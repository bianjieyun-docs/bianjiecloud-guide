# 一文看懂智能分流和全局代理：规则、全局、直连与 TUN 模式

智能分流、全局代理和直连模式有什么区别？日常为什么推荐智能分流，什么情况下要临时切到全局代理？本文同时解释系统代理和 TUN 模式的不同，帮你在边界云客户端里选对设置。

## 结论先看

- **日常优先使用智能分流**：国内网站直接访问，海外网站走边界云线路。
- **海外网站打不开时，可临时切换到全局代理**；使用完记得切回智能分流。
- **系统代理和 TUN 模式负责接管软件的范围**，其中 TUN 模式可以接管设备的全部网络流量，适合游戏、命令行工具等不读取系统代理的软件。

## 为什么现在值得看

如果你正在使用边界云客户端或 Clash 客户端，了解流量模式、接管方式和适用场景，可以更准确地处理国内外网站访问、软件不走代理等问题，并在速度、流量消耗和兼容性之间做出合适选择。

## 智能分流、全局代理和直连模式有什么区别

官方客户端的“流量模式”和 Clash 客户端里的“规则 / 全局 / 直连”是同一回事，决定了哪些网络请求经过边界云的线路。

| 模式 | Clash 中的名称 | 工作方式 | 适合场景 |
|---|---|---|---|
| **智能分流** | **规则** | 国内网站直接访问，海外网站走线路 | 日常使用，推荐一直开着 |
| **全局代理** | **全局** | 所有请求都走线路 | 个别网站被误判为国内、打不开时临时使用 |
| **直连模式** | **直连** | 所有请求都不走线路 | 临时停用加速，又不想断开客户端 |

## 为什么推荐智能分流

- **国内网站更快**：访问国内网站不绕道海外；
- **更省流量**：只有海外流量计入套餐用量；
- **少出问题**：银行、支付等国内服务不会因为海外 IP 触发风控。

## 什么时候用全局代理

当某个海外网站在智能分流下打不开，可以临时切到全局代理试试。用完记得切回智能分流，否则国内网站也会走线路，速度变慢、流量消耗更快。

## 系统代理和 TUN 模式又是什么

这是另一项设置，决定客户端“接管”哪些软件：

- **系统代理**：浏览器和多数遵循系统代理设置的软件都会走它，平时上网足够；
- **TUN 模式**：接管设备的全部网络流量，适合游戏、命令行工具等不读取系统代理的软件，需要管理员权限。

**两项设置互不影响**：TUN 模式下依然按智能分流的规则区分国内外流量。

## 常见问题

### 日常应该用哪个模式？

智能分流。国内网站直接访问，海外网站走线路，速度快也更省流量。

### 全局代理会多用流量吗？

会。全局代理下国内网站也走线路，流量消耗更快，用完记得切回智能分流。

### 游戏或命令行不走代理怎么办？

把接管方式改成 TUN 模式，它会接管设备的全部网络流量，首次开启需要管理员权限。

### 直连模式适合什么时候使用？

临时停用加速，又不想断开客户端时，可以使用直连模式；此时所有请求都不走线路。
