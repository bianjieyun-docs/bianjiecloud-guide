# Mac 安装边界云官方客户端：Apple 芯片与 Intel 版选择指南

## 一句话结论

在 Mac 上安装边界云官方客户端前，先通过“关于本机”确认设备显示的是“芯片”还是“处理器”，然后从下载页选择 Apple 芯片版或 Intel 版；安装完成后登录账号、选择线路，并根据软件是否走系统代理决定使用“系统代理”或“TUN 模式”。

## 适用场景

本文适合以下用户：

- 第一次在 MacBook、iMac、Mac mini、Mac Studio 或 Mac Pro 上安装边界云客户端；
- 不确定自己的 Mac 是 Apple Silicon（M 系列）还是 Intel 平台；
- 下载了 `.dmg` 安装包，但首次打开时看到“无法验证开发者”或“未打开”提示；
- 已经登录客户端，但浏览器、终端或其他软件没有按预期连接；
- 需要在智能分流、全局代理、直连和 TUN 模式之间选择。

Apple 官方说明中，“关于本机”会将 Apple 芯片设备标记为“芯片”，Intel 设备则显示“处理器”；这也是选择安装包时最可靠的判断方式。([support.apple.com](https://support.apple.com/zh-cn/guide/mac-help/mchlea7173f3/mac))

## 第一步：确认 Mac 的芯片类型

### 方法一：通过“关于本机”查看

1. 点击屏幕左上角的苹果菜单 。
2. 选择“关于本机”。
3. 查看硬件信息中的“芯片”或“处理器”一行。

根据显示内容选择安装包：

- 如果显示 `Apple M1`、`Apple M2`、`Apple M3`、`Apple M4` 等，选择 **MacOS-M 芯片**版本；
- 如果显示 `Intel`，选择 **MacOS-Intel**版本。

Apple 官方文档明确区分了这两种显示方式：搭载 Apple 芯片的 Mac 显示“芯片”，基于 Intel 的 Mac 显示“处理器”。([support.apple.com](https://support.apple.com/zh-cn/116943))

### 方法二：从系统设置进入

在较新的 macOS 中，也可以按以下路径查看：

```text
苹果菜单  → 系统设置 → 通用 → 关于本机
```

这里还可以查看 macOS 版本、内存、序列号和系统报告。([support.apple.com](https://support.apple.com/zh-cn/guide/mac-help/mchlea7173f3/mac))

### 不要仅凭 Mac 外观判断

同一系列 Mac 可能存在 Intel 版和 Apple 芯片版，仅凭 MacBook 外观、屏幕尺寸或购买年份不能准确判断。下载客户端前，建议以“关于本机”中的实际显示为准。

如果你使用的是较少见的旧款设备，或者页面显示内容与下载页说明不一致，不要自行猜测安装包，优先查看下载页的版本说明或联系官方客服。

## 第二步：从官方页面下载对应客户端

打开边界云下载中心，在“官方客户端”区域选择 macOS 安装包：

- **MacOS-Intel**：适用于“关于本机”中显示 Intel 处理器的 Mac；
- **MacOS-M 芯片**：适用于“关于本机”中显示 Apple 芯片的 Mac。

下载地址应以边界云官方页面为准：

```text
https://www.bianjiecloud.com/downloads
```

下载完成后，通常会得到一个 `.dmg` 文件。建议不要从来源不明的网盘、论坛附件或第三方打包页面获取客户端。macOS 的“门禁”机制会检查从互联网下载的 App 的开发者签名和公证状态，但这并不意味着用户可以忽略下载来源。Apple 也提醒，运行未经签名或公证的软件可能带来恶意软件和隐私风险。([support.apple.com](https://support.apple.com/zh-cn/102445))

## 第三步：安装 `.dmg` 文件

1. 双击下载好的 `.dmg` 文件。
2. 在弹出的安装窗口中，将边界云客户端图标拖到“应用程序”文件夹。
3. 打开 Finder，进入“应用程序”。
4. 双击边界云客户端图标启动。

如果系统提示是否打开从互联网下载的 App，请先确认安装包确实来自边界云官方页面，再继续下一步。

## 第四步：处理 macOS 首次打开拦截

### macOS 15 及更高版本

如果首次启动时看到“未打开某某 App”或类似提示，可以按以下路径操作：

1. 在提示窗口中点击“完成”。
2. 打开“系统设置”。
3. 进入“隐私与安全性”。
4. 向下滚动到“安全性”区域。
5. 找到关于边界云客户端被阻止的提示，点击“仍要打开”。
6. 输入 Mac 登录密码。
7. 在再次出现的确认窗口中点击“仍要打开”。

Apple 的官方流程是：先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认“仍要打开”。该选项通常只会在你尝试启动 App 后的一段时间内显示。([support.apple.com](https://support.apple.com/zh-cn/102445))

### macOS 12–14

对于 Monterey、Ventura 或 Sonoma，可以尝试以下方法：

1. 在“应用程序”文件夹中找到边界云客户端；
2. 按住 Control 键点按，或使用鼠标右键点按；
3. 选择“打开”；
4. 在确认窗口中再次选择“打开”。

部分系统也可以通过“系统设置 → 隐私与安全性”中的“仍要打开”完成授权。具体名称可能因 macOS 版本和系统语言不同而略有差异。

### 如果提示“已损坏，无法打开”

“已损坏”并不一定表示文件真的损坏，也可能是下载不完整、旧版本残留、签名验证失败或文件来源不可靠。建议按以下顺序处理：

1. 将旧的边界云客户端移到废纸篓；
2. 删除原来的 `.dmg` 文件；
3. 回到官方客户端下载页重新下载；
4. 重新安装到“应用程序”文件夹；
5. 再次尝试启动。

如果重新下载后仍然出现相同提示，不建议直接使用不明来源的“破解”或强制修改安全设置工具，应保留系统提示内容并联系官方客服。

## 第五步：登录账号

启动客户端后，在登录页填写官网注册时使用的邮箱和密码，然后点击“登录”。如果希望以后打开客户端时自动进入首页，可以勾选“记住密码并自动登录”。

登录页面通常还包含以下功能：

- **语言切换**：可在简体中文、繁體中文和 English 之间切换；
- **立即注册**：没有账号时进入注册流程；
- **联系客服**：登录遇到问题时，可从登录页面直接打开客服入口。

密码输入错误时，先检查邮箱地址、大小写和键盘输入法；如果确认账号信息正确但仍无法登录，再检查网络连接或提交工单，不要反复修改客户端配置。

## 第六步：选择线路

登录后进入左侧“线路”页面，可以根据需要选择：

- **自动**：由客户端选择当前可用的出口，适合不想手动挑选的用户；
- **按地区选择**：展开地区列表后，选择具体线路；
- **测速全部**：让客户端对列表中的线路执行检测，再根据客户端显示的状态进行选择。

线路名称中的地区通常用于表示出口所在地。需要注意的是，客户端页面状态属于客户端当时的检测结果，不应理解为永久稳定的线路质量保证；如果当前线路无法使用，可以回到线路页更换其他线路。

## 第七步：连接并允许网络权限

1. 返回客户端“首页”。
2. 确认已选择线路。
3. 点击中间的圆形连接按钮。
4. 首次连接时，如果 macOS 询问是否允许修改网络设置，点击“允许”。
5. 根据系统提示输入 Mac 登录密码或管理员凭据。
6. 连接成功后，再打开浏览器或其他需要网络访问的应用进行验证。

如果需要切换线路，可以点击“更换”，选择其他线路后重新连接。首页通常还会展示当前订阅的已用流量、剩余流量和到期时间；这些信息以客户端实际显示为准。

## 第八步：选择流量模式和接管方式

### 流量模式

客户端设置中的“流量模式”通常包括：

- **智能分流**：日常使用的推荐选项，根据规则决定哪些流量经过代理、哪些流量直连；
- **全局代理**：尽可能让系统代理范围内的网络请求通过当前线路；
- **直连模式**：暂时不使用代理线路，适合排查问题或访问本地网络资源。

智能分流与全局代理使用的是当前选择的线路，切换流量模式通常不会自动更换出口线路。

### 接管方式

接管方式决定客户端能够影响哪些程序：

- **系统代理**：适合浏览器和大多数遵循系统代理设置的软件；
- **TUN 模式**：接管更广泛的系统网络流量，适合部分不读取系统代理的终端工具、游戏或其他应用。

启用 TUN 模式通常需要管理员权限。TUN 模式并不等同于“所有软件必然正常”，具体效果还取决于应用自身的网络实现、系统权限和客户端版本。排查问题时，可以先使用系统代理验证浏览器，再根据实际需求启用 TUN。

## 第九步：终端命令不走代理时怎么处理

如果浏览器可以访问，但终端中的命令无法连接，常见原因是终端程序没有读取 macOS 系统代理。可以按以下顺序处理：

1. 将客户端接管方式切换为 **TUN 模式**，重新连接；
2. 如果不想启用 TUN，查看终端工具是否支持单独设置 HTTP、HTTPS 或 SOCKS 代理；
3. 关闭其他代理软件，避免多个程序同时修改系统网络设置；
4. 检查客户端是否仍处于连接状态，以及是否已获得网络扩展权限。

不要使用 `ping` 或 `traceroute` 的结果直接判断系统代理线路质量。ICMP 和部分诊断流量通常不会按照浏览器的系统代理路径转发；即使启用了 TUN，内核也可能对部分 ICMP 请求进行本地处理，因此结果不能等同于代理线路的实际访问表现。

## 常见问题

### 1. Apple 芯片 Mac 可以安装 Intel 版吗？

部分 Intel 应用可以在 Apple 芯片 Mac 上通过 Rosetta 运行，但这不是选择安装包时的首选方案。Apple 建议优先使用 Universal 或 Apple silicon 版本，以获得更好的兼容性和后续支持；Intel 应用首次运行时，系统可能提示安装 Rosetta。([support.apple.com](https://support.apple.com/en-euro/102527))

因此，显示 M1、M2、M3、M4 等芯片的 Mac，建议直接下载 MacOS-M 芯片版，而不是主动选择 Intel 版。

### 2. 为什么双击客户端没有“仍要打开”？

“仍要打开”一般需要在你先尝试启动 App 后，才会出现在“系统设置 → 隐私与安全性”的安全性区域。可以先关闭提示窗口，再重新启动一次客户端，然后回到该设置页面查看。([support.apple.com](https://support.apple.com/zh-cn/102445))

如果设备由公司或学校管理，管理员策略也可能限制相关选项。遇到这种情况，应联系设备管理员确认，不要为了安装软件而关闭系统安全保护。

### 3. 提示“已损坏，无法打开”怎么办？

先不要使用第三方修复工具。将旧 App 和旧安装包删除，然后从边界云官方客户端下载页重新获取与芯片类型匹配的版本。如果重新下载仍失败，保存完整提示信息、macOS 版本和 Mac 芯片类型，再联系官方客服。

### 4. 连接后网页打不开，应该先改什么？

先确认客户端首页显示已连接，再回到“线路”页面更换线路，并检查流量模式是否误设为“直连模式”。如果浏览器使用系统代理仍无法访问，可以暂时切换到另一条线路；如果只有某个应用打不开，则需要进一步判断该应用是否遵循系统代理，必要时再尝试 TUN 模式。

### 5. 为什么浏览器可以用，终端命令却不通？

浏览器通常会读取 macOS 系统代理，而终端程序可能使用自己的网络库或代理配置。可以启用 TUN 模式，或者按照具体命令行工具的官方文档单独配置代理。不要仅凭 `ping` 成功或失败判断代理是否生效，因为 ICMP 流量与浏览器的 HTTP/HTTPS 请求不是同一条路径。

### 6. 想使用 Clash Verge Rev 等第三方客户端怎么办？

边界云官方客户端之外，也可以根据自己的使用习惯选择支持 macOS 的第三方客户端，并手动导入订阅。第三方客户端的安装、配置字段和系统权限可能随版本变化，应以对应项目的官方文档为准。使用订阅链接时，不要公开发布或发送给无关人员；如果怀疑泄露，应及时在服务端处理订阅更新或更换。
