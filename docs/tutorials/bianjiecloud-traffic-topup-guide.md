# 边界云流量加油包购买与到账教程：季付、年付和按量订阅怎么加流量

## 一句话结论

边界云订阅流量不够用时，不需要重新购买套餐，也不需要更换订阅链接，可以登录官网进入对应的“订阅详情”页面购买流量加油包；付款完成后，流量会直接加到当前订阅，随后在客户端刷新订阅即可继续使用。

## 适用场景

本文适合以下情况：

- 季付或年付套餐的本月流量即将用完；
- 按量流量包仍未到期，但剩余流量不足；
- 客户端显示流量已用尽，但订阅本身还没有到期；
- 已经购买了流量加油包，需要确认是否到账；
- 想了解加油包是否清零、是否延长订阅有效期，以及不同订阅类型的购买区别。

加油包只增加流量，不会延长订阅到期时间。购买操作需要使用手机或电脑浏览器登录官网完成，官方客户端内暂时不能直接购买加油包。

## 加油包类型与有效期

边界云官网的订阅详情页会根据当前订阅类型展示适用的加油包，通常不会让用户选择不匹配的类型。原文公布的容量、价格和有效期如下，数据来自边界云加速官网公布的说明，具体以原文和购买页面显示为准。

| 订阅类型 | 50G 加油包 | 100G 加油包 | 流量有效期 |
| --- | --- | --- | --- |
| 季付、年付套餐 | ¥20 | ¥35 | 计入本月额度，到下一个流量重置日清零 |
| 按量流量包 | ¥50 | ¥100 | 不清零，用完为止 |

季付、年付套餐的加油包并不是永久流量。它会计入当前月份额度，并在下一个流量重置日与当月剩余流量一起清零。因此，如果距离流量重置日只剩一两天，建议先确认是否有必要购买。

按量订阅的加油包则直接增加到原来的按量订阅中，不改变原来的订阅链接，流量不设置月度清零时间，用完为止。

## 分步骤购买流量加油包

### 第 1 步：登录官网并打开订阅详情

1. 使用手机或电脑浏览器打开[边界云官网](https://bianjiecloud.com/)，登录购买订阅时使用的账号。
2. 进入顶部导航中的“用户中心”。
3. 打开“我的订阅”。
4. 找到需要增加流量的订阅，点击“查看详情”。

建议先核对订阅名称、到期状态和剩余流量，避免在多个订阅之间选错。官方客户端目前不能直接购买加油包，因此不要在客户端内反复寻找购买入口；正确做法是在浏览器中完成购买，之后再回到客户端同步。

### 第 2 步：选择适合当前订阅的容量

进入订阅详情页后向下滚动，找到“购买流量加油包”区域。根据页面显示选择 50G 或 100G 等可用容量，然后点击“购买”，在确认窗口中点击“确定”。

如果当前是季付或年付套餐，购买前重点查看页面中的流量有效期提示。加油包只在本月有效，到下一个流量重置日会清零；如果当前流量还没有接近用完，也可以先观察使用情况再决定是否购买。

如果当前是按量流量包，页面可能显示为“按量加油包”。这类加油包的流量会直接并入原订阅，不需要生成新的订阅链接，也不会因为月度重置而清零。

### 第 3 步：确认订单并付款

选择加油包后进入订单页面：

1. 确认订单中的订阅和加油包容量；
2. 选择页面提供的支付方式；
3. 如有可用优惠码，可在付款前填写；
4. 点击“立即支付”完成付款。

官网原文说明，付款前可以填写优惠码 `BJAPP`，减 5%。该优惠信息属于原文发布时的说明，使用时应以订单页面实际接受情况为准，不要根据旧订单或第三方转载内容判断优惠是否仍然有效。

### 第 4 步：检查订单状态和流量余额

付款完成后，先在订单页面确认订单状态。官网说明，付款成功后一般几秒内到账，订单状态会变为“已完成”。然后返回订阅详情页，检查以下两项：

- 套餐额度是否增加了对应的 GB 数；
- 剩余流量是否同步增加。

官网原文给出的示例是：购买 50G 后，套餐额度从 1,536 GB 增加到 1,586 GB。该数字是边界云加速官网原文中的示例数据，不能作为所有账号的固定额度或当前套餐标准。

如果订单已经显示“已完成”，但页面仍显示旧流量，可以先刷新浏览器页面，退出订阅详情后重新进入。仍未更新时，保留订单编号和付款记录，再提交工单咨询。

### 第 5 步：在客户端刷新订阅

流量到账后，订阅链接通常不需要更换。

- **边界云官方客户端**：点击右上角的刷新图标或“同步”，重新获取订阅状态；
- **Clash Verge Rev 等桌面客户端**：在配置或 Profiles 页面找到对应订阅，使用更新、刷新或重新拉取订阅的功能；
- **Shadowrocket 等第三方客户端**：在订阅管理页面手动更新订阅。

如果使用的是 Clash Verge Rev，建议从其官方 GitHub 仓库获取软件和版本信息，不要从来历不明的网盘或修改版页面下载。刷新订阅只用于同步订阅内容和状态，不会改变官网账户中的流量规则。

## 按量订阅如何加流量

按量订阅的购买步骤与普通加油包基本一致：

1. 浏览器登录官网；
2. 进入“用户中心”中的“我的订阅”；
3. 打开按量订阅的“查看详情”；
4. 找到“按量加油包”；
5. 选择 50G 或 100G，点击“购买”；
6. 完成付款并等待订单到账；
7. 回到客户端更新订阅或同步状态。

按量加油包的特点是直接添加到原来的按量订阅，原订阅链接不用更换；并且流量不按月清零，用完为止。需要注意的是，“不清零”不等于“永不过期”：如果原订阅已经到期，仍应按照页面要求续订或重新购买有效订阅。

## 常见问题

### 1. 加油包的流量会清零吗？

取决于订阅类型。季付、年付套餐购买的加油包会计入当月额度，到下一个流量重置日清零；按量订阅购买的加油包不清零，用完为止。

### 2. 订阅显示“已用尽”，还能购买加油包吗？

如果订阅仍在有效期内，可以购买加油包。到账后，流量会增加到当前订阅，通常可以恢复使用。如果订阅已经到期，则不能把加油包当作续期服务，需要重新购买或续订套餐。

### 3. 购买加油包会延长到期时间吗？

不会。加油包只增加流量，不改变订阅的到期日期，也不会把已过期的订阅重新激活。

### 4. 为什么找不到“购买流量加油包”？

常见原因包括：当前订阅已经到期、订阅已取消、登录的账号不是购买该订阅的账号，或者当前页面没有正确加载。可以先确认账号、订阅状态和浏览器页面；如果仍然没有入口，建议提交工单，并附上订阅名称或订单信息。

### 5. 付款后客户端还是显示旧流量，是否需要换订阅链接？

通常不需要换链接。先在官网订阅详情页确认订单状态和流量余额，再在客户端执行刷新、同步或更新订阅。如果官网已经增加流量而客户端仍未变化，优先检查客户端是否更新了正确的订阅条目，而不是重新创建订阅。

### 6. 季付或年付套餐快到流量重置日了，还要不要购买？

需要结合剩余使用时间判断。因为这类加油包会在下一个流量重置日清零，如果只剩一两天，购买前应先查看当前剩余流量、使用需求和重置时间；如果能够等待重置，可能不必立即购买。
