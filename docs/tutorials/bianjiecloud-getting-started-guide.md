边界云的使用流程很短：**注册 → 买套餐 → 装客户端 → 登录连接**。下面按顺序说明，每一步都附有详细教程的入口。

## 1. 注册账号

打开注册页，填写邮箱和密码即可。建议使用常用邮箱，找回密码、到期提醒都会发到这个邮箱。

## 2. 选择套餐并付款

在套餐页挑选适合自己的套餐：

- **季付、年付套餐**：按订单日每月重置流量，适合每天都要用的人；
- **按量流量包**：一次性总流量，不清零，用完为止，适合偶尔使用。

下单时可以填写优惠码 **BJAPP**，减免 **5%**。

付款成功后系统自动开通，不需要等人工处理。还没想好买哪种，可以看套餐选择指南。

## 3. 安装客户端

| 你的设备 | 推荐方式 | 教程 |
| --- | --- | --- |
| Windows 电脑 | 边界云官方客户端 | Windows 官方客户端 |
| Mac 电脑 | 边界云官方客户端 | macOS 官方客户端 |
| 安卓手机 | 边界云官方客户端 | Android 官方客户端 |
| iPhone / iPad | Shadowrocket | iPhone 使用教程 |

已经习惯 Clash 的用户，也可以继续用 Clash Verge Rev 或 Clash Meta for Android，导入订阅链接即可。

## 4. 登录并连接

打开官方客户端，用刚才注册的邮箱和密码登录，套餐和线路会自动同步。在“线路”页测速，选一条延迟低的线路，回到首页点击中间的连接按钮即可。

## 常见问题

### 边界云付款后多久能用？

一般 **1 分钟内**。付款成功后系统自动开通，打开官方客户端用同一个账号登录就能看到线路。

### 一个账号能在几台设备上用？

不限设备数量，电脑、手机、平板可以同时登录，所有设备共用套餐流量。

### iPhone 有官方 App 吗？

暂时没有。iPhone、iPad 可以用 Shadowrocket 导入订阅，步骤见 iPhone 使用教程。
