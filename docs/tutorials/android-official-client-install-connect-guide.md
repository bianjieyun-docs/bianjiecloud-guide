# Android 官方客户端安装与连接：边界云安卓 App 使用教程

**一句话结论：**安卓手机优先使用边界云官方客户端，按“下载安装 → 登录账号 → 允许通知和 VPN → 选择模式 → 点击连接”的顺序操作，通常不需要手动复制订阅链接。

## 适用场景

本文适用于以下情况：

- 第一次在 Android 手机上使用边界云官方客户端；
- 已经下载了 Android 安装包，但不清楚如何允许安装或完成授权；
- 登录后点击连接没有反应，或者误点了 VPN 授权弹窗中的“取消”；
- 想在“规则”“全局”“直连”之间切换；
- 想查看流量、到期时间、线路列表，或重置已经泄露的订阅链接；
- 连接一段时间后自动断开，希望检查通知权限、自启动和电池优化设置。

本文以边界云官网说明中的 **Android 客户端 1.1.1 版本**为基础。官网说明特别提示：如果手机上安装的是 **1.0.0 或更早版本**，需要先卸载旧版再安装新版，因为 1.1.1 更换了应用签名，旧版不能直接覆盖升级；已经安装 1.1.0 的用户可以直接安装 1.1.1，无需卸载。套餐、流量和订阅不受客户端升级方式影响。安装包校验值请以官网“开源许可与源码获取”页面公布的信息为准，不要使用来源不明的 APK 或他人转发的修改包。

## 一、下载安装 Android 官方客户端

### 1. 从官网进入下载页

使用安卓手机浏览器打开边界云官网，在下载页的“官方客户端”区域找到 Android 版本并下载。建议直接从官网进入下载页，不要通过搜索结果中的不明镜像、网盘或聊天群文件下载。

下载前可以先确认以下内容：

- 页面域名是否为边界云官方域名；
- 下载的文件是否为 Android 安装包；
- 文件来源是否与官网页面一致；
- 如果官网提供校验值，是否按照页面说明进行校验。

### 2. 允许当前浏览器安装应用

Android 8.0（API level 26）及更高版本通常需要针对具体来源应用开启“安装未知应用”权限。例如，使用 Chrome 下载 APK，就需要允许 Chrome 安装未知应用；如果使用系统浏览器下载，则需要为系统浏览器授予权限。Android 官方文档说明，这项权限是按安装来源分别控制的，而不是一次性对所有应用开放。

常见操作路径如下，具体名称会因手机品牌和系统版本略有不同：

1. 点击下载完成的 APK 文件；
2. 系统提示“禁止安装未知来源应用”时，点击“设置”；
3. 打开“允许来自此来源”或“允许安装未知应用”；
4. 返回安装界面，继续安装；
5. 如果系统出现安全扫描，先查看提示内容，再按照系统界面继续。

如果手机由公司或学校管理，管理员可能禁止从未知来源安装应用。此时不要尝试绕过设备管理限制，应联系设备管理员，或使用组织允许的安装方式。

### 3. 用电脑通过 adb 辅助安装

如果手机无法直接打开 APK，也可以在已经开启 USB 调试并安装 Android SDK Platform-Tools 的电脑上使用 `adb install`。Android 官方 adb 文档提供了通过 `adb install path_to_apk` 安装 APK 的用法，示例中的文件名需要替换为实际 APK 路径。

macOS 或 Linux 示例：

```bash
adb devices
adb install ./bianjiecloud-android.apk
```

Windows PowerShell 示例：

```powershell
adb devices
adb install .\bianjiecloud-android.apk
```

如果命令返回 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，通常表示手机中已安装的同包名应用与待安装 APK 的签名不匹配。边界云官网说明中，Android 客户端 1.0.0 或更早版本由于签名变化，需要卸载旧版后再安装 1.1.1。Android 开源系统的包管理器将签名不匹配归为 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，因此不要把这个问题误判为版本号降级。

如果命令返回 `INSTALL_FAILED_VERSION_DOWNGRADE`，含义不同：待安装 APK 的版本号低于手机中当前已安装的版本。此时应确认下载的 APK 是否为旧版本，不要仅凭这个错误判断为签名问题。

卸载旧版前应确认记得账号邮箱和密码，避免把“卸载客户端”误认为“删除账号”。

## 二、首次打开并登录账号

安装完成后打开 App，启动页通常停留一两秒，然后进入登录页面。

按以下顺序操作：

1. 输入在边界云官网注册的邮箱；
2. 输入账号密码；
3. 勾选同意《用户协议》和《隐私政策》；
4. 点击“登录”。

如果还没有账号，需要先在官网完成注册并购买相应服务，再回到客户端登录。客户端登录使用的是账号信息，不是订阅链接；官方客户端会根据账号状态同步套餐和线路信息，因此不需要像 Clash 或 sing-box 那样手动粘贴订阅地址。

### 登录失败时先检查什么

登录失败时，建议先按顺序确认：

- 邮箱地址是否输入完整，是否误加了空格；
- 密码大小写是否正确；
- 手机当前网络能否正常打开官网；
- 是否把订阅链接误当成账号密码；
- 是否使用了旧客户端，或者安装包并非来自官方页面。

如果只有客户端无法登录，而手机浏览器可以打开官网，可以先关闭客户端后重新启动，再检查系统日期和时间是否自动同步。若仍不能登录，保留错误提示和客户端版本信息，再提交工单。

## 三、允许通知和 VPN 连接

首次登录后，客户端可能依次请求通知权限和 VPN 连接权限。这两个授权的用途不同，但都可能影响使用体验。

### 1. 允许通知

通知权限用于在通知栏显示连接状态，方便查看当前是否仍处于连接状态以及快速断开。Android 13（API level 33）及更高版本对非豁免通知使用运行时权限 `POST_NOTIFICATIONS`；用户拒绝后，应用的普通通知可能无法显示。

因此，如果系统弹出通知权限请求，建议点击“允许”。如果之前拒绝过，可以到系统设置中找到该 App，进入“通知”重新开启。通知权限本身不等同于 VPN 连接权限：即使通知被关闭，也不代表一定无法连接，但你可能看不到状态栏提示。

### 2. 确认 VPN 连接请求

第一次点击连接时，Android 会显示系统 VPN 连接请求。此时点击“确定”，允许客户端通过 Android 的 VPN 接口接管手机网络；如果点击“取消”，客户端无法建立连接。

Android 的 `VpnService` 机制要求用户对 VPN 连接进行确认，并且同一用户或工作资料通常只能有一个活动 VPN 连接。VPN 应用运行期间，系统也会显示相应的连接状态提示。

授权成功后，手机顶部状态栏一般会出现钥匙形状的 VPN 图标。不同厂商可能使用略有差异的图标，但可以在系统下拉通知栏或“设置 → 网络和互联网 → VPN”中确认当前连接状态。

## 四、一键连接与出站模式

完成授权后，进入底部的“仪表盘”页面：

1. 点击右下角的播放或连接按钮；
2. 等待按钮变成暂停状态，并观察连接计时是否开始；
3. 查看流量统计数字是否出现变化；
4. 需要停止时，再次点击暂停按钮。

首次使用建议先保持默认的“规则”模式：

- **规则**：国内网站或应用直连，其他流量按照客户端规则处理，适合日常使用；
- **全局**：尽量让所有流量都经过线路，适合排查某个应用是否需要代理，但可能增加不必要的流量消耗；
- **直连**：不经过加速线路，适合临时恢复普通网络或对比问题是否由客户端连接引起。

模式名称和具体行为以当前客户端界面为准。切换模式后，建议关闭并重新打开一次目标网页或应用，因为部分应用会缓存连接状态。

## 五、选择自动线路或指定地区

点击底部的“代理”进入线路列表，可以看到以下常见选项：

### 自动

“自动”是默认选择，客户端会根据当前可用性和延迟情况选择线路。日常浏览、办公和普通应用使用时，优先保持自动即可，不需要频繁手动切换。

### 延迟测试

“延迟测试”会对线路进行客户端侧的延迟检测，界面通常会用信号格或颜色表示结果。它适合用于筛选当前响应较快的候选线路，但延迟低不等于所有网站都一定打开，也不代表下载速度、视频播放或特定应用兼容性一定更好。不要把一次延迟结果当成长期线路质量结论。

### 指定地区

如果某项服务需要特定地区入口，可以在列表中选择对应地区，例如日本、美国等。选择后返回仪表盘重新连接，再打开目标应用进行验证。

### 倍率线路

部分线路名称可能带有“5倍”等标识。根据官网说明，这类线路属于倍率线路，使用 1 GB 时会按照相应倍数扣除流量，适合在确有需要时临时使用。日常使用前应先确认当前套餐的流量规则，避免把倍率线路与普通线路混用。

## 六、查看流量、续费和重置订阅链接

### 套餐页面

进入“套餐”页面，可以查看已用流量、剩余流量和到期时间。若页面数据没有立即变化，可以点击右上角刷新图标，或打开套餐卡片右上角的“⋮”菜单，选择“同步”。

### 续费与流量加油包

进入“工具 → 账号”，点击“续费”后，客户端会打开官网套餐页面。仅仅是流量不足时，不一定需要重新购买完整套餐；可以根据官网页面提供的选项购买流量加油包。具体可购买项目和规则应以官网当前页面显示为准，本文不额外推测价格或套餐内容。

### 重置订阅链接

如果曾经把订阅链接发到公开群组、截图或不可信设备，建议在“工具 → 账号”中使用“重置订阅链接”功能。重置后，旧链接会失效；如果其他客户端仍在使用旧链接，需要在 Clash、sing-box 等客户端中重新导入新链接。

如果是在 iPhone 或 iPad 上使用 Shadowrocket，重置订阅链接后也需要在 Shadowrocket 中重新导入。Shadowrocket 的官方 App Store 页面面向 iOS/iPadOS，不是 Android 客户端，因此 Android 用户不能把它当作本教程中的安卓客户端使用。

重置订阅链接不会等同于修改登录密码，也不会自动替换第三方客户端中的旧配置。完成重置后，应检查旧设备、旧浏览器下载记录和聊天记录，避免再次泄露新链接。

## 七、访问控制、语言和后台运行

### 1. 访问控制

“工具”页面中的“访问控制”可用于指定哪些 App 走加速、哪些 App 不走。例如，可以让部分国内银行、外卖或本地生活应用保持直连，以减少兼容性问题。修改后建议重新打开目标 App，确认设置是否生效。

### 2. 切换界面语言

在“工具 → 设置 → 语言”中可以选择：

- 简体中文；
- 繁體中文；
- English；
- 默认，即跟随手机系统语言。

切换后通常立即生效，无需重启客户端。

### 3. 允许后台运行

部分手机厂商会主动限制后台应用，可能导致客户端被系统清理、通知消失或 VPN 连接中断。可以在系统设置中为边界云客户端检查以下项目：

- 允许后台运行；
- 允许自启动；
- 电池优化设置为“不优化”或“无限制”；
- 允许使用后台数据；
- 不要在系统最近任务列表中手动清理客户端。

不同品牌的设置入口可能位于“应用管理”“电池”“权限管理”或“自启动管理”中。不要为了保持连接而关闭手机全部安全防护，只针对官方客户端设置必要的后台权限即可。

## 常见问题

### 1. 点击连接后没有出现 VPN 授权弹窗怎么办？

先返回仪表盘再次点击连接。如果仍没有弹窗，可以打开系统“设置 → VPN”，查看是否存在旧的 VPN 配置；删除不再使用的旧配置后，重新打开客户端尝试。如果手机上同时安装了多个 VPN 类应用，也可能发生连接冲突，因为 Android 系统同一用户通常只能有一个活动 VPN 连接。

### 2. 不小心点击了“取消”，怎样重新授权？

回到仪表盘，再次点击连接按钮，系统一般会重新显示授权请求。如果没有显示，进入手机系统的 VPN 设置，删除边界云旧配置后重试。不同厂商的菜单名称可能不同，可以在系统设置中直接搜索“VPN”。

### 3. 状态显示已连接，但网页打不开怎么办？

按以下顺序排查：

1. 在“代理”页面执行一次延迟测试；
2. 选择信号显示较好的候选线路；
3. 回到仪表盘确认不是“直连”模式；
4. 关闭并重新打开浏览器或目标 App；
5. 临时切换到“全局”模式，判断是否为规则匹配问题；
6. 如果其他 VPN 应用正在运行，先断开或退出其他应用；
7. 仍无法解决时，记录客户端版本、手机型号、Android 版本、当前模式和错误提示，再提交工单。

延迟测试只能作为线路筛选参考，不应单独用来判断网页是否一定可访问。

### 4. 套餐页面流量没有更新怎么办？

先点击套餐页面右上角刷新图标，或者打开套餐卡片的“⋮”菜单并选择“同步”。如果客户端刚刚产生流量，服务端数据可能需要一定时间才能显示。多次刷新仍无变化时，记录账号邮箱、客户端版本和页面截图，提交工单时不要公开完整订阅链接。

### 5. 手机重启后连接自动断开怎么办？

检查客户端是否被系统禁止自启动，电池优化是否仍处于“优化”状态，以及通知权限是否被关闭。部分系统会在省电模式、清理后台或切换网络时暂停后台服务。先将客户端加入允许后台运行或电池白名单，再手动重新连接。

### 6. 想改用 Clash Meta for Android 或 sing-box，可以吗？

可以，但第三方客户端需要手动导入订阅链接，操作方式取决于客户端支持的配置格式。重置订阅链接后，第三方客户端中的旧订阅需要重新导入。使用第三方客户端前，请从其官方项目页面获取安装包或文档，不要下载来路不明的修改版。

Shadowrocket 是面向 iOS/iPadOS 的客户端，不属于 Android 客户端选项。若需要在 iPhone 或 iPad 上使用它，应从 Apple App Store 获取对应应用，并按照其客户端界面导入订阅。

无论使用哪种客户端，都应妥善保护订阅链接，并遵守当地法律法规。
