# 套餐到期、流量不足如何处理：加油包与订阅切换指南

## 一句话结论

如果只是当前周期内临时流量不够，购买流量加油包即可继续使用原订阅；如果套餐即将到期，或每月都需要更多流量，则应重新购买合适的套餐。购买新套餐后，官方客户端可以在账户内切换，Clash Verge Rev、Shadowrocket 等第三方客户端通常需要复制并导入新的订阅链接。

## 适用场景

本文适用于以下情况：

- 当前套餐尚未到期，但本月流量快用完或已经用完；
- 不确定应该购买流量加油包，还是直接购买更大流量的套餐；
- 套餐即将到期，希望提前购买下一份套餐；
- 已经购买新套餐，但不知道如何在客户端中切换；
- 使用按量流量包，想确认加购流量是否会在流量重置日清零。

本文不讨论测速结果、线路质量、节点在线率或解锁情况，只整理套餐购买、流量补充和订阅切换流程。具体页面名称、套餐规则和订单状态，应以账户中实际显示的内容为准。

## 先判断：购买加油包还是重新购买套餐？

可以根据使用频率和套餐周期做判断：偶尔只差少量流量时，加油包更直接；如果每个月都不够用，通常应重新购买容量更大的套餐。两类操作的主要区别如下。

| 你的情况 | 建议操作 | 原订阅链接是否需要更换 | 流量是否在重置日清零 |
| --- | --- | --- | --- |
| 当前套餐仍在有效期内，偶尔超出流量 | 购买流量加油包 | 通常不需要 | 季付、年付套餐的加油包计入本月额度，到下一个流量重置日清零 |
| 按量流量包快用完 | 在订阅详情页购买按量加油包，或重新购买按量流量包 | 通常不需要更换原链接 | 按量流量包的加油包不清零，用完为止 |
| 套餐即将到期 | 重新购买季付、年付套餐或按量流量包 | 第三方客户端通常需要导入新链接 | 以新订阅的规则为准 |
| 每月都需要额外购买流量 | 直接购买流量更大的套餐 | 购买后需要切换新订阅 | 以新套餐说明为准 |

## 购买流量加油包

### 1. 打开当前订阅详情

登录官网后，依次进入“用户中心”→“订阅”→“查看详情”。先确认当前打开的是正在使用、且确实需要增加流量的订阅记录。

购买前建议核对以下信息：

- 当前订阅的类型；
- 当前剩余流量；
- 套餐到期时间；
- 流量重置时间；
- 账户中是否存在多个订阅。

如果账户中有多条订阅记录，不要直接在不确定的记录下购买，避免加购流量与实际使用的订阅不一致。

### 2. 选择流量加油包

在订阅详情页找到“购买流量加油包”，根据当前订阅类型选择对应的流量包。以下金额、流量和清零规则来自边界云加速官网公布的说明，实际以购买页面和订单结算结果为准。

| 当前订阅类型 | 50G 加油包 | 100G 加油包 | 使用规则 |
| --- | ---: | ---: | --- |
| 季付、年付套餐 | ¥20 | ¥35 | 计入本月额度，到下一个流量重置日清零 |
| 按量流量包 | ¥50 | ¥100 | 不清零，用完为止 |

### 3. 完成付款并核对余额

付款成功后，新增流量通常会在几秒内加入当前订阅。由于加油包是附加在原订阅上的，一般不需要重新复制订阅链接，也不需要删除客户端中的原配置。

完成付款后，建议重新打开订阅详情，确认剩余流量已经更新。如果页面暂时没有变化，可以依次尝试：

1. 刷新订阅详情页；
2. 退出当前页面后重新进入；
3. 等待片刻后再次核对余额；
4. 保留订单号、付款时间和付款凭证。

如果较长时间后仍未到账，不要重复购买，建议使用订单信息提交工单说明情况。

## 套餐到期时重新购买

### 1. 重新选择套餐

当前说明中没有通过按钮直接延长原套餐到期时间的“续费”流程。套餐临近到期时，应进入套餐页，重新选择季付套餐、年付套餐或按量流量包。

如果希望减少到期时的操作间隔，可以在原套餐到期前几天完成购买。提前购买并不意味着原套餐立即失效，原订阅和新订阅应分别以账户中的到期时间和状态为准。

### 2. 填写优惠码并付款

下单时可以尝试填写优惠码 `BJAPP`。原说明写明该优惠码可减免 5%，这一优惠信息来自官网原文；实际是否适用、适用哪些套餐以及是否仍在有效期内，应以结算页面最终显示为准。

付款完成后，原说明表示新订阅一般会在 1 分钟内开通。开通后先回到用户中心确认：

- 新订阅是否已经出现；
- 套餐类型是否正确；
- 流量额度是否正确；
- 到期时间是否符合订单内容。

### 3. 在客户端切换订阅

#### 官方客户端

打开客户端，点击右上角当前显示的套餐名称，在订阅列表中选择新购买的套餐。如果新订阅暂时没有显示，可以退出账户后重新登录，再检查订阅列表。

#### Clash Verge Rev

Clash Verge Rev 是面向 Windows、macOS 和 Linux 的桌面客户端，官方项目和发布文件以其 GitHub 页面为准。购买新套餐后，按以下流程处理：

1. 在用户中心复制新套餐的订阅链接；
2. 打开 Clash Verge Rev 的订阅管理页面；
3. 新增订阅或更新对应配置；
4. 选择新导入的配置；
5. 启用该配置后，再确认客户端当前使用的订阅名称。

下载客户端时，应根据设备架构选择官方发布页提供的安装包。Windows 设备如果系统信息显示为 x64，应选择 x64 版本；如果显示“基于 ARM 的处理器”，则应按照下载中心或官方发布页对 ARM64 版本的说明选择，不要仅凭文件名猜测。Linux、macOS 以及其他架构也应以官方发布页的可用文件为准。

#### Shadowrocket

Shadowrocket 适用于 iPhone 和 iPad，不是 Windows 客户端。购买新套餐后，在用户中心复制新的订阅链接，再在 Shadowrocket 中新增订阅或更新配置，最后选择新配置使用。

第三方客户端需要导入的是新套餐的订阅链接，不是订单页面地址，也不是加油包购买页面地址。购买加油包时，通常继续使用原订阅链接即可；重新购买套餐后，才需要确认是否生成了新的订阅链接。

## 想更换流量更大的套餐

如果当前套餐容量长期不够用，可以直接购买流量更大的套餐，再按照上面的客户端切换方法使用新订阅。当前说明中没有补差价升级流程，因此不要默认原套餐可以通过补差价自动转换为更大套餐。

可以按下面的思路选择：

- **只是偶尔月底不够用**：优先考虑流量加油包；
- **连续多个周期都不够用**：重新购买更大流量的套餐；
- **套餐马上到期**：直接购买下一份适合的套餐，并预留客户端切换时间；
- **刚刚买错套餐**：先核对订单和订阅状态，不要立即重复下单。

如果付款后发现套餐没有按预期开通，建议准备订单号、付款时间、账号邮箱和页面截图，再提交工单说明问题。

## 常见问题

### 1. 购买加油包后，需要重新导入订阅吗？

通常不需要。加油包是增加到当前订阅中的流量，原订阅链接和客户端配置一般可以继续使用。付款后可以刷新订阅详情，确认流量余额是否发生变化。

只有在重新购买套餐后，第三方客户端才通常需要复制并导入新的订阅链接。具体是否生成新链接，以用户中心显示为准。

### 2. “续费”会同时增加流量吗？

当前说明中没有直接续费功能。需要增加当前套餐流量时，应购买对应的流量加油包；需要继续使用到新的套餐周期时，应重新购买一个套餐。这两个操作不能混为一谈。

### 3. 季付、年付套餐的加油包为什么会清零？

官网原说明写明，季付、年付套餐的加油包会计入本月额度，并在下一个流量重置日清零。因此，购买前应确认自己只是短期补充流量，还是需要长期保留未使用额度。

按量流量包的加油包按照原说明不清零，用完为止。实际规则仍应以订阅详情页和订单说明为准。

### 4. 按量流量包用完后，必须重新申请新链接吗？

不需要。可以在原订阅详情页购买按量加油包，新增流量会加入原订阅，原链接通常可以继续使用；也可以重新购买一个按量流量包。

购买后建议刷新订阅详情，核对剩余流量。如果客户端显示异常，再检查客户端是否仍在使用原订阅配置。

### 5. 新套餐已经购买，为什么客户端里看不到？

可以按照以下顺序检查：

1. 确认付款是否成功；
2. 登录用户中心，确认新订阅是否已经生成；
3. 官方客户端尝试退出账号后重新登录；
4. 第三方客户端复制新订阅链接并重新导入；
5. 确认复制的是新订阅链接，而不是旧链接或订单页面地址。

如果账户中已经出现新订阅，但第三方客户端仍未显示，应检查导入操作是否成功，并确认当前启用的是新配置。

### 6. 可以提前购买新套餐吗？原套餐会立即失效吗？

原说明表示，原来的订阅会保留到自身到期时间。提前购买的主要作用是预留下一份套餐，减少到期时的操作间隔。购买后仍应在用户中心和客户端中分别确认当前订阅状态。

### 7. 套餐到期前多久购买比较合适？

建议在原套餐到期前几天购买，并预留付款、开通和客户端切换时间。用户中心会显示到期提醒，也可能向注册邮箱发送邮件。如果没有收到提醒邮件，可以检查垃圾邮件文件夹，并确认注册邮箱能够正常收信。

### 8. 购买加油包后可以把流量保留到下个月吗？

不能一概而论。季付、年付套餐的加油包按照官网原说明计入本月额度，并在下一个流量重置日清零；按量流量包的加油包则按照原说明不清零，用完为止。购买前应先确认当前订阅类型和流量重置规则。
