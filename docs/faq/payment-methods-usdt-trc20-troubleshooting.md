# 边界云付款方式与 USDT TRC20 支付排查指南

## 一句话结论

下单后应以订单页实际显示的渠道为准：通常包括支付宝、微信和 USDT（TRC20）；法币支付按订单页面完成付款，使用 USDT 时必须核对 TRC20 网络、转账金额和订单有效期，付款后不要重复支付。

## 适用场景

本文适合以下情况：

- 第一次在边界云下单，不确定是否支持支付宝、微信或 USDT；
- 订单已经付款，但用户中心暂时没有显示新订阅；
- 使用 USDT 付款时，不确定应该选择哪条区块链网络；
- 订单页面看不到某个付款渠道；
- 订单已经超时或被取消，不知道是否可以继续付款；
- 需要了解优惠码、发票和付款凭证相关说明。

边界云的付款方式会以当前订单页为准。不同订单、金额或时间段显示的渠道可能不同，因此不要仅根据其他订单的截图判断当前订单是否支持某种付款方式。

## 支持哪些付款方式

下单后进入订单页，在付款方式区域查看当前可用渠道。官网说明通常包括以下三种方式：

1. **支付宝**：在订单页选择支付宝，按页面提示完成付款。
2. **微信**：在订单页选择微信，按页面提示完成付款。
3. **USDT（TRC20 网络）**：使用支持 TRON 网络的数字货币钱包或交易平台转账。

如果订单金额较大，部分支付渠道可能因为单笔金额上限而不显示。此时可以返回订单页，查看其他可用渠道；不要为了使用某个渠道而拆分或重复创建付款，除非订单页面或客服明确要求这样操作。

TRC-20 是运行在 TRON 网络上的同质化代币标准，和 ERC-20、BEP-20 不是同一条网络。TRON 官方文档将 TRC-20 定义为基于 TVM 的代币标准，因此在选择网络时应以钱包或交易平台明确显示的 **TRON / TRC20** 为准。([developers.tron.network](https://developers.tron.network/docs/token-standards-overview))

## 付款步骤与到账检查

### 1. 创建订单并查看渠道

登录边界云账号，选择需要的订阅或流量包并创建订单。创建后先确认：

- 订单金额是否正确；
- 订单是否仍在有效支付时间内；
- 页面显示的是支付宝、微信还是 USDT（TRC20）；
- 如果使用优惠码，折扣是否已经反映在应付金额中。

付款前建议保留订单号，后续查询或提交工单时需要用到。不要向已经关闭或过期的订单继续付款。

### 2. 使用支付宝或微信付款

在订单页选择对应的支付渠道，按照页面跳转或二维码提示完成支付。付款完成后返回订单页，刷新页面查看订单状态。

付款成功后，系统一般会自动开通，通常在 **1 分钟内**完成。开通后进入用户中心的“我的订阅”，查看新订阅是否已经出现；官方客户端可以重新登录，或点击右上角刷新按钮同步订阅信息。

### 3. 使用 USDT（TRC20）付款

使用 USDT 付款时，重点核对以下三项：

1. **网络必须是 TRC20**：在钱包或交易平台的提币页面选择 TRON / TRC20 网络。不要把 ERC20、BEP20 或其他网络的资产转入 TRC20 付款地址。
2. **金额必须完全一致**：转账金额要与订单页面显示的金额一致，少转或多转都可能导致系统无法自动确认。
3. **订单必须仍在有效期内**：订单超时后应重新创建订单，不要继续向过期订单显示的地址转账。

提交转账前，建议逐项核对收款地址、网络和金额。区块链转账通常无法像普通支付订单一样简单撤回，网络选错或向过期订单转账可能无法自动识别。涉及数字资产转账时，请同时遵守当地法律法规，并遵守所使用钱包或交易平台的规则。

### 4. 付款后刷新订阅

付款成功后，可以按以下顺序检查：

1. 刷新订单页面，确认订单状态是否从“未支付”变为已支付；
2. 进入用户中心的“我的订阅”，确认新订阅是否出现；
3. 官方客户端重新登录，或者使用右上角的刷新、同步功能；
4. 如果使用 Clash、sing-box、Shadowrocket 等第三方客户端，待订阅开通后再更新订阅内容。

第三方客户端是否立即显示新配置，取决于客户端自身的订阅更新时间。付款状态和订阅是否开通，应优先以边界云用户中心显示为准，而不是只看客户端缓存。

## 优惠码与发票说明

### 优惠码 BJAPP

官网原文说明，下单时可以在“有优惠码？”处填写 `BJAPP`，减免订单金额的 **5%**；每个账号最多使用 **3 次**，季付、年付套餐和按量流量包均可使用。优惠码是否生效，应以订单页面重新计算后的金额为准。

### 发票与报销凭证

官网说明边界云由海外团队运营，暂不提供发票。如果付款后需要报销凭证，应在付款前确认所在单位能够接受何种付款记录或订单凭证，避免付款后才发现无法满足报销要求。

## 订单超时或取消后的处理

未付款订单超时后会自动关闭，关闭本身不影响重新下单。已关闭的订单不能继续付款，需要重新创建订单并使用新订单页面显示的金额、付款渠道和地址。

尤其是 USDT 付款，不要保存旧订单地址后反复使用。重新下单后，应以新订单显示的信息为准，重新核对网络、金额和支付时限。

## 常见问题

### 1. 边界云支持支付宝和微信吗？

支持。官网说明订单页通常会显示支付宝、微信和 USDT（TRC20）等付款方式，但具体渠道以当前订单页实际显示为准。若某个渠道没有出现，可能与订单金额上限或当时的渠道可用性有关，可以选择页面列出的其他方式。

### 2. USDT 付款应该选择什么网络？

选择 **TRON / TRC20** 网络。TRC-20 是 TRON 网络上的代币标准，不能与 ERC-20 或其他链的转账网络混用。转账前应同时核对收款地址和订单页面的网络说明。([developers.tron.network](https://developers.tron.network/docs/token-standards-overview))

### 3. 付款成功但订单仍显示未支付怎么办？

先等待几分钟并刷新订单页面，不要重复付款。官网说明付款结果可能存在延迟；如果超过 **15 分钟**仍未开通，应提交工单，并附上订单号和付款截图。截图可以遮挡姓名、地址、交易所账号等无关的个人信息，但应保留客服核对所需的订单状态和交易信息。

### 4. USDT 少转或多转还能自动开通吗？

官网说明转账金额必须与订单页面显示的金额完全一致，少转或多转都可能导致无法自动确认。遇到这种情况不要继续向同一订单重复转账，应保留交易记录、订单号和转账信息，并提交工单说明情况。

### 5. USDT 转错网络还能找回吗？

官网说明目前只支持 TRC20 网络，其他网络转入的资产无法自动识别。由于不同钱包、交易平台和区块链网络的处理规则不同，不能承诺转错网络后一定可以找回。转账前务必确认网络；已经转错时，应尽快保存交易哈希、订单号、转账时间和收款地址，并联系相关平台及边界云客服。

### 6. 订单已经超时，还能继续付款吗？

不能。未付款订单超时后会自动关闭，已关闭订单不能继续付款，需要重新创建订单。尤其不要继续向过期订单的 USDT 地址转账，以免系统无法把转账与新订单关联。

### 7. 付款后客户端没有显示新订阅怎么办？

先到用户中心“我的订阅”确认订阅是否已经开通。若网页端已经显示新订阅，官方客户端可以重新登录或点击刷新、同步；第三方客户端则需要更新订阅。如果用户中心仍没有开通，按照“付款成功但订单仍显示未支付”的步骤处理，不要只反复刷新第三方客户端。

### 8. 优惠码 BJAPP 可以使用几次？

官网说明每个账号最多使用 **3 次**，可用于季付、年付套餐和按量流量包。填写后应检查订单页的最终金额，确认折扣已经生效再付款。
